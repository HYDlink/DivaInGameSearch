DIVA In-Game Search
中文说明：见 README.zh-CN.txt

A search mod for Hatsune Miku: Project DIVA Mega Mix+.
Press Ctrl+F in-game to search songs, modules, hairstyles and accessories,
then jump straight to what you picked.
You can only switch to items you already own. The mod never buys anything
for you and never starts a song for you.

=== Installation ===
1. Install DivaModLoader:
   https://github.com/blueskythlikesclouds/DivaModLoader
2. Close the game and put the whole DivaInGameSearch folder into the game's
   mods folder.
3. Enable it in your mod manager.

=== Updating and uninstalling ===
To update, close the game and overwrite the folder. Skip settings.ini if you
want to keep your settings.
To uninstall, delete the folder. Your save data and other mods are not affected.

=== Controls ===
Ctrl+F                        Open search; if already open, select all text
Tab / Ctrl+Tab                Next / previous tab
Arrow keys                    Choose a result and difficulty
Enter or click                Locate on the current page
Double Enter or double-click  Jump there from another page
Ctrl+P / Ctrl+E               Preview / equip
Esc or click outside          Close

The hotkey, font size, row height, opacity and language can be changed in
settings.ini.

=== Game updates ===
If a game update changes the executable from the verified version, locating
and equipping turn off automatically until the mod is updated.
