# 服装卡片操作与双击跨页交互规格

日期：2026-10-31。优先级：用户本轮新要求高于旧的单击跨页描述。实现顺序与证据边界见 [实现计划](../docs/CUSTOMIZATION_ACTION_IMPLEMENTATION_PLAN.md)。

## 卡片构成

- 沿用已有自适应图片格子、真实精灵比例与宽图跨列规则。现有固定图片区与名称区保持高度，悬浮不得撑高卡片或触发布局重算。
- 名称区保持两行：显示名；人物和稳定 ID。图片右上角可标「已装备」，但仅来自已验证装备读回；无证据不显示。
- 图片底部内嵌一行操作条，卡片左右各约8像素内边距，按钮高约30～32逻辑像素、间距6～8像素；缩放沿用字体／DPI。两按钮分别「换装」「预览」，首个用低饱和薄荷青强调，第二个用中性深灰。
- 指针在卡片范围内立即显示操作条，移入按钮不会消失。键盘聚焦／当前搜索选择也显示操作条，触屏使用先选择再点按钮。图像及文字不因动作条移动；悬浮不触发自动预览。
- 默认选中描边仍为薄荷青；悬浮采用较浅边框。图片自身色彩不被大面积高亮底覆盖。按钮的目标是其卡片稳定 ID，独立于搜索选中和原生高亮。
- 长名称可省略，名称提示保留完整文本。按钮必须是真正可交互的 ImGui item，不能只在 DrawList 上画字。

## 点击与命中

1. 主体单击改变搜索选择。当前目标原生页可保留现有原位定位；不在目标页时只选中，不切页。
2. 鼠标左键双击同一卡片主体才允许跨页；到达后只高亮目标，不装备、不自动预览。卡片图片、名称与主体留白同属主体。
3. 两按钮与主体是互斥命中区域。点按钮后不派发主体 click／double-click；按钮处连续双击最多提交一次该按钮动作。
4. 双击以稳定 ID、种类及查询修订确认同一项，不能只用屏幕坐标或当前行号。滚动、搜索更新、重新布局导致项目替换时清空双击候选。
5. 当前非模型页时按钮显示禁用态；提示「双击卡片进入模型页后使用」。原位动作不在后台替用户切页。
6. Enter、底部定位、快捷键不得作为跨页备选入口。已在目标页可做原位定位；非目标页底部写「双击结果进入模型页」。

## 动作状态

| 状态 | 展示与行为 |
| --- | --- |
| 可用 | 换装／预览可点击，按钮所在卡片决定目标 |
| 正在跨页／加载 | 禁止重复事务；底栏显示真实阶段与取消能力；不会因悬浮别项改变目标 |
| 临时预览 | 原生模型预览接收输入，搜索内容保存；提示原生Esc退出；预览不是新跨页路由 |
| 预览退出 | 核对临时显示已恢复、装备没被本动作改变；恢复原搜索查询与滚动 |
| 已装备 | 装备标记更新；更换按钮改成禁用「已装备」，预览仍按能力开放 |
| 未拥有／拥有状态未知 | 更换禁用并说明原因；预览是否可用独立判定，不能自动购买 |
| 范围／槽位未认证 | 动作禁用，显示具体上下文原因，不偷偷使用槽位0或默认人物 |
| 饰品／发型能力未完成 | 相同视觉结构可保留，但未验证动作明确禁用 |

底栏一次显示一条「正在进入模型页」「已定位 · 名称」「已更换 · 名称」或具体拒绝原因。选中项信息可与反馈合并。临时成功反馈短暂停留，不把日志和内存字段显示给普通玩家。

预览默认不弹自制的静态大图替代原生试穿。设计草图中的放大图仅演示搜索面板暂时让出及恢复的交互；它不是已经实现的3D模型预览。

## 当前版本迁移点

`customization_ui.cpp`现有整卡 `InvisibleButton` 单击会调用 `RequestLocate`，且 `RequestDetails`实际提交定位；名称并不能代表其真实语义。实施时改成明确的动作种类与触发来源，避免按钮与卡片同时消费同一次输入。已有页面／目录校验、后台查询修订、可见图像缓存和方向导航继续保留。

图稿 `customization-actions.fragment.html` 是本地可编辑的交互示意，内含的图片路径仅引用忽略目录里的研究样本。角色名称、拥有状态及原生页状态在示意中用于交互演示，不是运行时认证结果，不携带游戏地址或写入接口。


## 1.0.11 用户最新交互覆盖

模型页内点击其他人物服装的预览／换装，无须先定位；按钮事务自己逐帧准备目标分类，执行后恢复原分类和高亮。分类准备不等于跨页面，不扩大主页／选曲等起点的按钮导航权限。仅定位的鼠标双击跨页规则保留。角色过滤首次全部，此后始终保留用户选择，当前游戏角色不覆盖筛选。
