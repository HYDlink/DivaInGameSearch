# 搜索面板交互

> 2026-10-31新增服装悬浮动作与双击跨页要求，以 [CUSTOMIZATION_ACTIONS_SPEC.md](CUSTOMIZATION_ACTIONS_SPEC.md) 为准。跨页只能由搜索结果卡片主体的鼠标左键双击发起，Enter／按钮不自动跨页。下文保留原版本及基础浏览记录，不能据其旧描述关闭已经实机确认的模型原位定位。

> 2026-11-01用户补充：歌曲结果主体双击或难度按钮单击均可进入选曲页并定位；名称单击和Enter仍只原位定位。服装换装／预览按钮受理后立即隐藏搜索窗，预览正常退出后保留恢复搜索逻辑。搜索窗外部左键可关闭；下拉弹层与IME候选先处理自身输入。

入口为普通选曲页 Ctrl+F。搜索框直接检索歌曲，曲包通过来源下拉框筛选，候选结果使用两行名称与来源，右侧固定对齐难度与 PVID。

工具区按行组织，行首标签强调，字段名置于控件之前：

1. **筛选：** 曲包、风格、含有难度；难度可恢复为全部。
2. **排序：** 下拉框、刷新曲库、重载样式合并一行。不再显示定位难度下拉框，直接点击结果中的难度按钮定位；原有键盘难度导航仍保留，操作提示只留在结果栏。

点击曲名按定位行提交；点击等级按对应难度提交。上下键改变当前结果，Enter 提交，Esc 关闭。每次打开同步游戏当前难度与风格。缺失难度不自动替换。

搜索框内长按上下连续移动歌曲，累积同帧重复消息，滚动跟随高亮；左右调整定位难度，只经过当前风格的可用谱面，不回绕。换曲保留难度偏好，缺失时 Enter 给出提示，不静默降级。选中歌曲的目标难度加粗边框。Tab / Shift+Tab 可访问其他控件，此时方向键与 Enter 交由控件处理；弹窗先由 Esc 关闭。

逐字输入等待 300 毫秒再执行后台检索，组词期间不检索。结果使用查询版本号和不可变曲库快照，旧任务不能覆盖新输入或新曲库。Enter 跳过等待时间，异步查询完成后仅提交一次最新结果；游戏帧不等待任务。更新期间保留旧结果用于浏览，并标出“搜索中”，禁止直接定位旧列表。

难度颜色沿 EASY 蓝、NORMAL 绿、HARD 黄、EXTREME 红、EX EXT 紫；独立深色按钮底和彩色边框保证在选中行仍能辨识。悬停与按下进一步提亮，不可用项变暗。

定位成功必须通过真实字段确认；失败保留查询与明确说明。不能自动演奏。独立预览只检验 UI，不访问游戏内存。设计 HTML 为早期静态草图，以实际共用 C++ UI 为准。

顶部「歌曲／服装／饰品」共享单一窗口和 Ctrl+F。各模式保留独立条件，互切清空尚未处理的方向和确认动作。服装／饰品的 Enter 仅打开详情，不能进入歌曲定位器；原生定位能力默认关闭。角色未知时默认初音未来并显示原因，共通饰品包含在具体角色结果中。

定制搜索文本内上下按格子行移动，左右编辑文字；Tab 进入单一格子键盘入口后，左右按列、上下按行，Home/End 到首尾，PageUp/PageDown 按可见行翻页。缺角末行尽量保留列意图；混合方向按消息到达顺序消费。Tab 不逐个遍历所有卡片。详情／下拉框先由 Esc 关闭；组词期间输入交给 IME。只展示已导入元数据，缺图使用明确占位，未导入显示说明。完整依据与后续本机验证见 docs/CUSTOMIZATION_SEARCH_PLAN.md。
