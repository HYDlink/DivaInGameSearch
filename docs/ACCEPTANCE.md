# 验收范围

1.0.0 的测试分为自动验证、原生界面预览与实际游戏操作，三者不能相互替代。

| 范围 | 结果与边界 |
| --- | --- |
| 检索与数据 | 核心断言覆盖 Unicode、别名、读音、组合过滤、排序、来源合并等 |
| 定位状态机 | 覆盖稳定菜单、错误状态、超时、恢复、缓存与真实高亮分离，以及直接路径不请求菜单切换 |
| 输入与 DLL 宿主 | 原生输入协议测试与 DLL 回调检查通过；不能等同全部 IME 实机通过 |
| UI | 共用 DX11/WARP 预览检查分组、彩色按钮、选中行与长列表 |
| 实际游戏 | 用户确认直接定位可用；连续实际读回包含同曲极限→EX 极限、简单→困难，以及换曲同时切难度 |
| 菜单备用协议 | 受控工具验证两次歌曲/困难定位，不代表 UI 中提供两种模式 |

实际定位实测主要为街机风格。跨风格、Eden、不同构建、IME、DPI、所有 Mod 组合及长期稳定性尚需补充。快速定位后的封面或作者同步存在已观察到的局限。

复现自动检查：

```powershell
./scripts/build.ps1
./scripts/verify.ps1 -GameDirectory '游戏安装目录'
./scripts/check-profile.ps1 -GameDirectory '游戏安装目录'
```

游戏内回归应核对菜单高亮、实际难度、风格、可见画面与诊断。不要仅凭函数返回或请求缓存宣称成功；不要为测试自动开始演奏或改写存档。
