# Cloud 开发补丁合入检查

状态：已应用到本地开发分支 `integrate-cloud-patch`，未部署游戏、未替换已发布的 1.0.0。原补丁文件保持不变。

## 合入内容

- 歌曲列表长按导航、左右选难度、Tab 控件导航及目标难度边框。
- 150 毫秒输入防抖、后台查询、旧结果丢弃及名称规范化缓存。
- 丢失或迟到的按键释放恢复、应用失活清理及输入摘要诊断。
- 服装与饰品的本地元数据导入、检索、筛选、格子导航与详情浏览。

歌曲原生定位适配 `game.cpp` 与 `selector.cpp` 未被补丁修改。服装／饰品的原生上下文、定位、装备、存档写入与预览能力仍禁用；真实数据需另行导入，演示数据只在独立预览显式启用。

## 本地检查与修正

Windows MSVC 编译成功。核心检查通过 63 项断言，定制物品基础检查通过 53 项；五组 CTest、完整输入/DX11 宿主、搜索视图、曲库审计与 DLL 回调检查通过。歌曲面板和服装演示格子的原生 WARP 截图已检查；演示格子不能算实际游戏或真实元数据验证。

仅消息测试最初在快速退出时崩溃：受控宿主退出未等待仍在访问 C++ 运行库的后台任务。已在 `Host::Shutdown` 等待曲库及查询任务结束，补充“查询尚未结束时退出”的回归；该等待不在游戏帧或 DllMain 中执行。修复后的消息生命周期测试连续八次通过。测试进程同时设置自身错误模式，系统异常不再弹出阻塞桌面的错误框。

这些是本地自动与预览结果，尚未覆盖此次补丁的真实游戏输入法、截图失活、物理长按以及歌曲定位全流程回归，不能继承 1.0.0 的实机结论宣称新输入逻辑已经验证。
