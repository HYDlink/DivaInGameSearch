# 服装定位、预览与换装实现计划

日期：2026-10-31。状态：实施计划与交互设计，尚未接入产品 DLL。本计划以用户最新要求覆盖旧文件中不一致的点击规则。

## 目标与交付范围

在现有服装图片格子上增加按目标稳定 ID 执行的「预览」「换装」，并把已验证的原生跨页协议接入插件。保留现有歌曲搜索、目录、图片缓存与后台调度。先交付服装 Module，再补发型和饰品自己的选择、预览及装备协议。

**跨页导航只能由鼠标左键双击搜索结果 item 发起。** 单击卡片、Enter、悬浮按钮、底部定位按钮、筛选与搜索自动完成，都不能隐式发起跨页。已经位于目标原生页时，允许保留当前版本的单击／Enter原位定位。

悬浮是显示操作，不触发游戏动作。预览与换装直接绑定按钮所在卡片，无须先选中它；不能误用当前搜索选中、旧原生高亮或搜索结果行号。

## 已核实的依据与尚缺的证据

| 能力 | 当前依据 | 实施限制 |
| --- | --- | --- |
| 现有模型列表稳定 ID 定位 | 1.0.6 用户实机确认；`src/module_locator.*` | 复用已验证上下文及跨角色路径，不能拿旧报告的禁用状态覆盖当前实现 |
| 外层及自定义子页路由 | `research/OUTER_NATIVE_ROUTING_VERIFIED.md` 的同会话14阶段 | 只覆盖已报告的主页、选曲、自定义起点；脚本成功不等于产品集成完成 |
| 不改变高亮的服装预览／更换 | `research/CURRENT_NATIVE_ROUTING_RESEARCH.md` 的 direct-preview-equip-01 | 在当前模型分类的真实列表内验证过 ID 0、316；不是任意 ID／人物／槽位认证 |
| 饰品 | `research/ITEM_SELECTION_OBSERVATION.md` 的两轮只读对照 | 部位与高亮是已观察字段；稳定 ID 映射及动作仍待验证，禁止调用候选入口冒充完成 |
| 发型 | 自定义页路由已验证 | 搜索领域、稳定目标映射与动作协议需要补齐，不能套用模型回调 |

模型动作回调已记录为 RVA `0x695250`，command 7 预览、3 普通更换；1／0涉及购买，不调用。外层正式请求为 `0x2C4BB0`，而 `0x2C4BE0`仍只是未主动验收的候选。全部地址仅用于构建 profile 核查，必须同时遵守报告的对象、线程、生命周期和步骤前提；不能只复制一个 RVA 调用。

## 最终输入规则

| 输入 | 已在目标原生页且上下文可用 | 主页／选曲／其他自定义子页 |
| --- | --- | --- |
| 单击卡片空白／图片／名称 | 更新搜索选择，并可沿用现有原位定位；不换装 | 只更新搜索选择，提示双击可进入目标页 |
| 双击同一卡片主体 | 合并为一次原位定位请求 | 唯一允许创建跨页路由请求的入口，到达后定位；不附带预览或换装 |
| 鼠标悬浮 | 显示该卡片「换装」「预览」 | 显示同样按钮，但禁用并提示「双击卡片进入模型页后使用」 |
| 点击预览 | 以该卡片稳定 ID 请求临时预览，不要求先改变原生高亮 | 不跨页，按钮禁用 |
| 点击换装 | 以该卡片稳定 ID 更换已拥有、可装备且范围已认证的服装 | 不跨页，按钮禁用 |
| Enter／底部定位 | 最新结果可做原位定位 | 只给双击提示，不创建导航权限 |
| Tab 到动作按钮后 Enter／空格 | 仅激活当前按钮，不能再触发卡片定位 | 与鼠标按钮相同，禁用跨页 |
| F3、Esc等游戏自然操作 | 用户仍可自然切页／退出；适配器使过期请求失效 | 不把自然按键等同于搜索结果的自动导航授权 |

“只有双击跨页”同样约束歌曲及其他领域未来接入统一路由的请求入口，不改变已有选曲页内点击难度的行为。筛选分类不等于切换人物槽位；更改卡片所属人物不得静默改玩家实际表演角色。

## 界面方案

详细像素与状态约定见 [交互规格](../design/CUSTOMIZATION_ACTIONS_SPEC.md)。保留当前石墨灰底、薄荷青选中描边、模型图片和双行名称／人物／ID。没有新增常驻右侧详情面板。

图片下沿放固定高度、半透明外观但不透过文字的操作条，包含「换装」「预览」两按钮；卡片名称区不被遮挡。选中／键盘聚焦项也显示操作条，保证无需鼠标悬浮也能访问操作。按钮区预留在图片内部，不改变卡片高度、列宽或滚动位置。

只有经过运行时独立读回才显示「已装备」。搜索选中描边、原生列表高亮、临时预览和已装备标记分别表达，不能共用一个 selected 布尔值。底栏保留一条当前操作反馈；跨页进度、预览及错误占用该位置，不堆叠弹窗。

跨页完成后只定位，是否关闭搜索面板沿用当前定位成功设置。开始预览时让出游戏输入并保存搜索查询／滚动／选中，预览结束后恢复搜索面板；换装成功后保留面板便于继续比较。不得在预览退出时自动再次预览，也不得把更换混入预览。

## 结构与接线

1. 增加独立的动作请求与状态，区分 `Locate / Preview / Equip`、`CardSingleClick / CardDoubleClick / HoverButton / Keyboard / Footer`。请求至少包含 `{kind,id,character,slot,scope,contextGeneration,catalogFingerprint,queryRevision,serial,origin}`。未认证字段保留 Unknown，不伪造初音／槽位0等写入上下文。
2. 用统一提交网关计算 `requiresNavigation`。若为真且 origin 不是已核对的卡片左键双击，立即返回 `NeedsDoubleClick`，不得排队或先切页再拒绝。Preview／Equip还要检查已在可操作模型页，即使调用者伪造 origin 也不授予它们导航能力。
3. 单独封装 `NativePageReader` 与 `NativePageRouter`，复用报告的按类型读取、当前场景树验证、原生退出与进入协议。`module_locator`继续负责列表身份及稳定目标定位，不让 UI 自己读写游戏对象。
4. 单独封装 `ModuleActionExecutor`。从当前真实可用列表按 ID 唯一查找 record，取得当前模型 scene／回调绑定，在匹配的原生游戏线程帧末执行；默认不调用列表定位函数、不改列表高亮。跨分类时，先完成已认证分类刷新并重新取得目标，若会破坏“高亮不变”承诺则明确降级说明或禁用，不偷偷定位后当作直接动作。
5. 所有入口共用串行事务、取消代数与错误反馈。一次预览／换装进行中，不接受重复动作。UI 关闭可取消未执行请求；已经完成的换装不得因关闭窗口被后台自动反向写回。

建议新增 `native_page_router.*`、`customization_action.*`，在 `customization_ui.*`、`mod.cpp`、`host.*`接线，并扩展现有 `module_locator.*`能力报告与守卫。实际文件拆分以避免循环依赖为准，不顺手重写歌曲选择器。

## 路由及动作事务

### 跨页定位

`捕获双击目标 → 验证构建／起点 → 原生退出必要层级 → 请求外层或兄弟页 → 等待页身份稳定 → 等待列表身份可用 → 重取人物／槽位／范围 → 按稳定ID定位 → 跨帧核对 → 完成`

每阶段按真实条件推进，分别设超时；不使用固定 Sleep 等待。页面存在、列表可用和图片素材就绪是不同条件；定位不必等所有缩略图加载，但必须确认目标列表及记录身份。导航期间不执行预览／换装。

首次双击锁定目标和角色／范围意图。路由预期产生的新对象不当成异常；使用 route serial 与明确阶段校验。用户自然切页／切槽、非预期对象替换、目录改变才取消或拒绝；不能在每次自身跨页时盲增代数导致必然自取消。

### 原位预览

`验证页面与目标 → 记录装备与高亮基线 → 原生临时预览 → 等待加载／预览状态 → 核对目标显示 → 接受原生退出 → 核对装备仍为基线 → 恢复搜索状态`

不能只凭 `controller+0x320/+0x338` 相等判预览成功；报告已证明正常装备后这些字段也能保留目标。需内部状态、实际显示目标及装备值交叉确认。恢复只恢复临时预览，不写回可能已经被用户主动改变的装备。

### 原位换装

`验证当前范围／槽位 → 验证目标存在、已拥有且可装备 → 调普通更换 → 核对已装备目标及显示 → 完成`

原生拥有／锁定判定尚需补证，目录条目、名称和图片均不能代替。先保持未认证范围不可换装。普通换装不增加重复确认弹框；按钮本身就是用户的更换指令。游戏原生保存按原生机制发生，不承诺“完全无存档影响”，不直接调用未知保存或购买入口。

### 取消和恢复

请求发出前可立即取消；原生加载或退出已受理时等待安全边界，不连续堆叠反向请求。若允许自动恢复来源页，只能是原双击事务内、上下文仍一致且已验证的有限恢复，不产生新的导航意图。无法认证恢复时停在已知安全状态并报出实际所在页。已成功的换装不自动撤销。

## 实施顺序与完成标准

| 阶段 | 具体工作 | 通过条件 |
| --- | --- | --- |
| A：输入与界面 | 悬浮操作条、稳定卡片身份、按钮命中分流、双击门禁、反馈与焦点 | 单击／Enter／两个按钮无法发起跨页，双击主体恰好一条路由；按钮双击也不冒泡成卡片双击 |
| B：页面读取与路由 | 产品 profile、对象树、外层与子页跨帧状态机 | 以新 DLL 复验研究的14阶段及错误起点，不用 AHK／Frida替代产品核心实现 |
| C：模型原位动作 | 直接预览、退出恢复、普通更换、已拥有与范围判定 | 搜索选中A／原生高亮A时点击B按钮实际操作B；已验证同分类直接动作不改变A高亮；装备与预览独立读回 |
| D：组合与边界 | 多次提交、用户改页、过期目录、弹层、未拥有、目标消失、不同人物／槽位／范围 | 只开放明确认证能力，拒绝无副作用；失败保留搜索与具体原因；现有歌曲定位、输入和帧开销不回归 |
| E：扩展发型／饰品 | 稳定ID映射、部位、绑定、无装备项及独立动作 | 每种能力分别提供实机证据；模型command和偏移不套用到饰品／发型 |

A 可先用独立共用原生 Preview 完成。B/C 前必须补运行时拥有状态、当前槽位／共通或单曲范围，以及被调用对象的生命周期守卫；不以0／316的研究样本白名单冒充正式拥有检查。

本计划不承诺把发型／饰品的未完成逆向当成已知实现工作。首批可交付为服装的双击路由与已认证上下文内的预览／换装；发型、饰品页面可导航，但其未验证动作继续禁用并说明原因。

## 验证清单

- 使用真实 ImGui 输入事件测试跨帧双击，绑定 `{kind,id,queryRevision}`；同位置换了搜索结果、滚动、失焦、IME组词或跨两张卡片不得构成双击。使用 ImGui 的双击时间／距离设定，不硬编码一次固定毫秒值。
- 卡片主体与按钮按互斥命中区域处理；按钮按下／释放不计入主体双击，不让整卡 InvisibleButton 抢走子按钮输入。短时间重复点击仅执行一次动作。
- 双击中的首个单击在已有模型页可以产生原位高亮，但不得提前创建路由；实际执行时合并同目标未提交的定位，避免双份请求。
- 键盘按钮激活、底部定位与外部调用同样受网关约束，不能只在 UI 涂灰。搜索旧结果、目录重载及 generation 变化使旧动作失效。
- 预览期间 Esc 恢复原装备；预览未结束时禁止换装，退出后重新校验。换装进行中显示处理中，完成后以独立装备读回显示已装备。
- 最终产品测试使用正式 DLL、无临时修正探针；每条实机路径保留操作前后截图、字段日志与构建 profile。自动测试、交互草图、原生 Preview 与实机结果分开登记。
