# 发型按歌曲检索

发型页与模型页共用歌曲名称、英文、中文别名、假名、罗马音和 PVID 检索，同一个输入也保留原有发型名称及 ID 结果。输入搜索本身不切歌、不跳页、不更换装备；用户点击结果后才走既有发型操作入口。

关联链为：歌曲演出角色与推荐 COS → 有效模型目录中的唯一模型 → 同人物且 `bind_module` 等于该模型稳定 ID 的唯一 KAMI 发型。模型 ID 与发型 ID 属于不同编号空间，不能用同 ID 直接转换。例如本机初音模型 0 对应默认发型 500，巡音模型 42 对应默认发型 804。

推荐角标、歌曲匹配数量、来源筛选及“推荐说明”复用模型页规则。推荐显示歌曲关联的全部人物；人物筛选继续作用于直接名称结果。其他人物发型仍仅供浏览，不能借歌曲推荐绕过当前歌者、槽位、拥有或设置范围守卫。

找不到绑定发型或存在多个候选时，列入“推荐说明”，不选第一个、不按名称猜测，也不退回同 ID。目录或推荐快照变化后，模型和发型分别作废旧查询，后台只读取值快照。

本次离线验证：18 项 CTest 全通过，包括故意使用不同模型／发型 ID 的关联、多人物推荐、多语歌曲及 PVID、相同 ID 的错误候选排除、绑定歧义拒绝、真实视图查询无自动导航和推荐快照失效。用户录制视频期间未操作游戏；本功能尚未部署或实机验收。

构建验证命令：`./scripts/build.ps1`。仅准备安装包：`./scripts/package.ps1`。部署必须等用户再次确认。
