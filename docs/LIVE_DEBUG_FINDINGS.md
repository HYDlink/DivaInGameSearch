# 定位排错经验

本文保留可复用结论，不公开逐时刻的个人运行日志或机器路径。

稳定选曲时 current/next 不一定相等。已核查 PC 构建中普通选曲为 5/6、控制值 1，播放列表为 6/7、控制值 1。菜单切换协议需要经过后者，误判会把玩家留在中间页面。

实际高亮 PVID、上次请求缓存、演奏对象和风格偏好是不同数据。演奏对象的 PVID 在选曲阶段可能为 -1，请求缓存也可能保留旧歌。通过已知手动操作做前后只读对照，才能确认字段语义。

正式直接路径通过 PC 原生列表重建、筛选刷新与索引高亮完成，不要求进入播放列表。实机记录已确认同曲与跨曲的难度变化，尤其覆盖 EX EXT。

成功验证同时参考真实高亮、难度、风格及截图。截图通道失败时，开发工具提供目标窗口 GDI/PrintWindow 方式；截图只作观察，不代表全部字段同步。已见封面或作者显示滞后，需要继续研究原生预览刷新。
