日期：2026-10-30。本文为持续实施记录，不代表完整功能已交付。

## 交付目标

一个 Mod 安装包自动列出官方、DLC 和启用 Mod 的服装，支持名称、别名、ID、角色及来源筛选，显示自动读取的真实图片，定位游戏原生服装列表；保留歌曲搜索。不要求玩家手工导出、填写清单、安装 Python/.NET 或使用开发机资源目录。

## 并行实施与所有权

- 主任务：架构、目录整合、宿主图片接线、构建、发布与部署检查。
- native_locator：新增定位适配器、game/mod 接线；依据已交接实验实现，不重复研究扫描。
- automatic_assets：新增自动资源接口及固定版本资源组件；官方 CPK、Mod sprite、后台解码与缓存。
- native_grid_ui：共用 ImGui 界面、几何导航、图片与定位注入接口。
- catalog_regression：自动目录及归档边界回归，不修改生产实现。

## 已有结果

自动 FArc/FArC 实体读取已接入生产目录，真实样本得到20/1/75条定义；X旧式名称在已核实构建和明确实体关系下映射997。此前6项自动验收通过，仅代表当时源码。后续整合必须重新构建验证。

## 当前接口约定

目录提供 catalogFingerprint；UI代数与原生上下文代数独立。图片 provider 轻量查询全部结果尺寸，仅可见项及少量邻近项触发后台请求；线程受控上传DX11。定位由UI回调提交稳定ID，适配器核对原生页面、列表和generation，不用查询结果行号替代原生索引。
