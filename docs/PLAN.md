# 维护路线

1.0.0 聚焦游戏内歌曲搜索与原生菜单定位。运行时保持 C++ DLL 架构，不引入浏览器、网络服务或 Python 后端。

近期优先处理预览资源同步、跨风格与输入兼容性回归。后续研究服装 Module、发型及饰品搜索；名称、别名、来源与列表 UI 可以复用，原生菜单定位需要分别核实。

新功能先定义实际菜单的完成条件，再研究对象与调用路径。把已编码、已构建、自动测试和实机验收分开记录。定位只负责高亮目标，演奏、装备确认与持久化不得静默混入搜索动作。

研究入口：[原生定位的两种路线](research/NATIVE_SELECTION_METHODS.md)、[服装研究](research/MODULE_SEARCH_FEASIBILITY.md)。
