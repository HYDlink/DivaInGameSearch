# 1.0.11 歌曲推荐服装、原生预览换装与跨页跳转

- **直接按歌曲找服装**：在服装页输入歌曲名称，复用歌曲搜索的原名、英文、中文别名、假名、罗马音、PVID匹配与排序，展示多角色推荐服装；推荐来自游戏已加载PVDB，不需要额外导表，不会因搜索自动切歌。
- **双击跨页**：歌曲名称主体双击或难度按钮单击可进入选曲页并定位；服装卡片主体双击可进入模型页。名称单击和Enter保留原位操作。
- **原生预览和换装**：模型页悬浮按钮使用稳定服装ID，支持其他人物分类；受理后隐藏搜索，保留真实拥有、槽位、范围及独立装备读回。旧预览可先自动退出，再接续定位、预览、换装或歌曲跳转；退出保留原浏览分类与高亮。
- **服装显示语言**：补读官方PC语言表，游戏内按当前语言加载服装名称，保留Mod多语言覆盖和原名回退；中文不再默认显示实体表里的日文。
- **界面整理**：歌曲工具区压为两行，移除定位难度下拉框、重复说明和Mod名称搜索开关；保留来源筛选，统一结果文字及服装标签。隐藏未完成的饰品和开发用性能监测入口。
- **修复**：保留角色／来源／排序选择，修复Megpoid等Mod服装图片依赖加载，以及Mod重复官方脚本路径导致《リンちゃんなう！》等歌曲漏搜。

歌曲与服装搜索等功能已由用户确认经过实际游戏测试。最终构建14项CTest及完整离线verify通过；README两张截图来自同一界面源码，推荐图使用已采样值和真实目录。补充的语言读取、入口隐藏和预览接续路径没有在本轮新增实机操作测试，不扩大为全部构建、槽位、风格或Mod组合通过。特殊泳装推荐继承、发型与饰品原生动作仍未提供完整支持。

更新时先退出游戏，解压覆盖本Mod并保留自己的settings.ini、aliases.toml；不要删除包内三个DLL。版本沿用既有1.0.11，本次没有自行升版。

# 1.0.0

首次正式发布 DIVA 游戏内搜索。这是一个人与 AI 编程助手协作完成的 Vibe Coding 项目。

- 游戏内原生搜索面板，默认 Ctrl+F。
- 曲名、英文、别名、假名、罗马音、PVID 与 Mod 检索。
- 曲包、风格、难度筛选及结果排序。
- 点曲名或具体等级，在当前选曲页定位歌曲与难度；不会自动演奏。
- 筛选、定位、排序分行显示，难度按钮强化边框与悬停反馈。
- Windows x64、静态 CRT，运行时无需外部服务；发行附源码及许可证。

实际游戏确认了街机风格下换歌和难度切换，包括 EX EXT。其他风格、Eden、更多构建、IME/DPI 与预览资源同步仍有待完善，详见 README 的支持边界。
