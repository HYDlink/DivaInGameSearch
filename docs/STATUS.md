# 项目状态

版本：**1.0.0**。日期：2026-10-29。

歌曲检索、Mod 检索、来源合并、筛选、排序、原生 UI 与直接定位已实现。实际游戏确认了同曲切换难度、换曲同时切换难度，包括 EX EXT；当前实测主要为街机风格。

工具区已拆为筛选、定位、排序三组，标签在控件前方；难度按钮使用独立深色底、彩色边框及悬停反馈。这些最后的 UI 调整已构建并检查共用原生预览，不能据此宣称所有输入法与显示配置已测。
