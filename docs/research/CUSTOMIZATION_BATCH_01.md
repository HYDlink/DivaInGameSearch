# 服装定位批量实验 01

日期：2026-10-29；时间均为北京时间。范围为当前运行构建、初音未来、歌者 1、曲目单独设置、过滤全。本文是观察与静态候选分析，**尚未找到经验证可由插件调用的原生服装定位接口**。

## 目标、已有证据与假设

目标是区分列表位置、操作菜单、候选试穿与退出恢复，并收敛原生调用链。已有位置 156→155→156 的玩家操作对照，以及候选试穿后控制器两处 0→316 的单点观察。待验证假设为：位置与物品 ID 分离；相邻物品试穿时 ID 切换；退出试穿恢复原模型且不经更换操作。

## 采集范围与完整性

同一 Frida Session `d50330e6-8ca0-4fa5-bdb3-04fb802722a2`，脚本 `batch-module-monitor-v1.js`；200 毫秒采样限定字段，三次一致记录稳定快照，每五秒心跳。本次状态记录含 17 个稳定快照、31 个心跳，没有消息截断。最后交付心跳达第 775 次采样。用户确认全部步骤完成，第 3 步打开菜单后曾停留；按状态变化而非固定秒数标注阶段。

主动末态页面和控制器快照在同一会话中取得，随后显式关闭会话；关闭结果 target_state=unknown，不代表关闭游戏。原始批量证据：`artifacts/customization-research/20261029-batch01-evidence.json`，主时间线 Evidence `ev_bb6f750fd1c17231613729a3df72d420f68ef0eedc6170342125e5f72cea590e`。后续状态树与静态候选将另存总结证据包。本轮没有 Interceptor、NativeFunction、模拟输入或游戏内存写入；游戏动作由玩家完成。200 毫秒轮询及稳定过滤可能漏掉短瞬态，不是函数调用追踪。

## 新增可确认的观测关系

以下偏移均相对本轮已识别对象，不是跨版本 ABI 承诺。

- 模型页面 +0x110：推荐项 156、左邻 155、推荐跳回 156，试穿和退出期间位置保持。已确认在当前条件下跟踪列表位置；零基性质、其他分类与过滤规则未验证。
- 控制器 +0x320 与 +0x338：进入相邻项目试穿时均为 394，退出均回到 0；推荐项目试穿时均为 316，再退出均回到 0。已确认在本轮区分两件试穿模型；二者各自是请求、显示还是装备临时缓冲仍未知，不能写入它们代替调用。
- 控制器 +0x64：本轮试穿稳定时为 2，退出后为 3，作为加载／显示状态候选；不命名未经验证的枚举。
- 页面 +0x60：菜单打开时出现对应位置 155／156，关闭并稳定后为 -1，试穿过程暂时保留。它与弹层目标关联，但不能作为当前高亮的通用替代。
- 页面 +0x20：试穿稳定时为 3，列表为 2；它也会在 F1 当前模型查看时为 3，单字段不足以区分两种查看入口。

名称表把 394 对应「向上向上！(0)」、316 对应「无上之选(-5)」。结合用户动作、之前画面与本轮试穿 ID，建立两点局部对应；尚未读取完整原生列表，不能宣称完成 ID→索引通用映射。

## 排除项

- 排除 F1 作为高亮候选试穿入口；F1 查看当前已设定模型，候选试穿走 Enter 菜单的「预览」。
- 控制器 +0x80 在本轮始终为 316，排除它作为本轮当前试穿模型 ID；不直接认定它是推荐 ID。
- 页面 +0x120、+0x2C8 保持 156，排除它们作为即时当前列表位置的充分依据。
- 排除把菜单停留视为试穿完成，以及把推荐跳转简化成只写位置字段。
- 若干向量外形窗口含不可读指针形状，排除直接按 Module* 数组解释；真实元素类型仍未知。
- 没有更换、购买或存档函数调用实验；不能从本轮证明隐式持久化从未发生。
