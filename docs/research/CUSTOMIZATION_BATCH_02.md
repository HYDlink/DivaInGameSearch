## 目标与边界

已有证据：初音未来分类位置 155／156 的双向移动和推荐跳回；试穿 394／316 后退出回到默认模型。尚未证明跨分类选择上下文、有效列表切换与推荐路径。

## 新增确认的关系与排除项

- 控制器 +0x40 在受控分类移动中为 0／1／2，分别对应初音未来／镜音铃／镜音连。它是当前条件下的角色分类字段，不是已装备人物或歌者槽位。
- 页面 +0x110 跟踪分类内位置；铃列表在 0 向左移一次后为 97，结合 +0x11C=98，支持本列表零基索引及边界回绕。不能把每个分类的位置 0 当同一物品 ID。
- 页面 +0x11C 为当前列表长度候选，随分类呈现 244／98／89。尚未遍历原生列表或核对所有条目，不能将这些数字推广为完整游戏拥有物品数。
- 推荐返回同时恢复分类、列表长度和位置。页面 +0x2C／+0x30 在当前分类没有对应目标时为 -1／-1，在初音未来为 0／156；它们不是当前高亮的通用替代，具体是装备／推荐关联缓存仍未知。
- 全程控制器 +0x320／+0x338 均为 0，符合未进入候选试穿；控制器 +0x80 始终 316，排除其作为当前角色分类或当前列表位置。不能仅凭恒定值将其认定为推荐 ID。
- 指针链和虚表检查未触发失效，但不能由地址保持就断言没有原地析构／重建。动画不证明生命周期重建，也不证明可省略刷新流程。
- 控制器 +0x38 全程为 1、+0x3C 为 0；未进行 Q/E 槽位对照，不命名为已验证槽位字段，canReadContext 仍不能因此启用。
