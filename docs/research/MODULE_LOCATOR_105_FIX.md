# 1.0.5 模型页误拒绝修复与证据

2026-10-30晚间，用户在真实模型列表点击定位无反应。1.0.4日志确认UI确有提交ID3／40，定位器统一返回“未检测到当前有效的模型服装页”。这属于生产实现缺陷，不能归咎于用户没有进入列表。

## 根因

只读真实模型帧观测：页面状态1、弹层-1、分类0、当前列表244项、索引67、实际ID137；虚表及控制器根关联一致，原始上下文字段0。控制器+320／+338均为125。画面显示正常模型列表，无操作弹层。

旧实现把这两个完整语义未认证的原始字段命名为previewA/previewB，并要求同时为0，导致正常列表始终不可用。此前试穿实验出现394/316、退出后0，只能证明该轮值变化，不能推导“非0就是正在试穿”。1.0.5改称rawModelA/rawModelB，撤销零值约束；仍记录并比较其变化，保持页面状态、原始上下文、弹层、配置身份、列表、人物和取消代数守卫。拒绝时返回最近一次具体上下文原因。
