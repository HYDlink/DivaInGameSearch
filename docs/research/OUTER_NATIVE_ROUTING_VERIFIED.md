# 原生外层路由与端到端定位实机报告

日期：2026-10-31。本文补充此前自定义子页及服装动作报告，不代表产品DLL已接入，也不代表任意游戏状态均可跳转。

## 实验目标、前提与方法

目标是找到可供C++插件在游戏线程调用的正式外层请求接口，实现主页／选曲／自定义之间导航，再接到现有服装稳定ID定位。此前已确认父页进入模型、模型／发型／饰品循环和服装预览／更换，本轮复用，不重新扫描。

构建SHA256为 `6F4DF714C28515C93B3023E7D6DAFA9095DD8835F762D54DB1726FB8BC04504D`。RVA均相对本次游戏主模块；堆对象、线程号及上下文必须每次重新取得。原始证据位于忽略目录 `artifacts/native-routing-research/20261031/`，这些是本机Frida日志，没有REA MCP Evidence ID。

自然输入只用已有AutoHotkey；每轮同一Frida Session，阶段快照含UTC时间和经过秒，连续三次满足页面及过渡断言才继续，截图按阶段保存。所有会话均已关闭并分离。没有购买、换装或直接写全局current／next。自定义自然退出会出现保存中，不能承诺无存档影响。

## 已确认接口

| RVA | 签名／作用 | 证据等级与边界 |
| --- | --- | --- |
| `0x2C4BB0` | `void requestMode(int mode)` | 自然调用参数、运行时指令及主动调用成功；主页到自定义用7，到选曲用2 |
| `0x2C4A40` | 外层模式控制帧 | 完整运行时函数序言及控制逻辑已解码；在其onLeave一次性提交模式请求成功 |
| `0x2C48B0` | `void initMode(int mode,int sub)` | 自然模式切换内部初始化函数；记录到主页进选曲参数2／47，**不作为插件绕过退出阶段直接调用的入口** |
| `0x1DE750` | `uint8 activateCustomize(int pvid,void* context)` | 自然R为800／null，主页自定义初始化为0／null；选曲主动调用通过 |
| `0x6EECD0` | `void hideSelector(song*,uint8)` | 自然R随后调用、静态true分支已确认；主动激活后按顺序调用true通过，不调用false分支 |
| `0x6EDC40` | 选曲控制帧 | 复用已有PC参考代码；匹配真实选曲对象，在onLeave执行R等效协议 |
| `0x6968D0` | 场景管理器目标请求 | 本轮扩展验证父页请求Finish键8；实际退出由原生状态机和外层任务完成 |

`0x2C4BE0`是子页面请求候选：运行时指令与ReDIVA参考源码`shift_next_mode_sub`相符，但**本轮未主动调用验收**。`0x2C4820`疑似子模式控制函数，本轮没有将其作为主动调用接口。

## 新增字段与来源区分

外层结构位于 `base+0xCC61078`。结合自然调用前后与既有参考源码，确认当前模式+0、待请求模式+4、模式过程+0xC、模式切换字节+0x10、当前子页面+0x1C、待请求子页面+0x20、子页面过程+0x28和子页切换字节+0x2C。这解释了原有全局 `0xCC61094/98/A0` 是同一结构中的子页面字段。

不能把相邻时间计数或打包读取出的整数当成独立菜单枚举。只读快照中的`menuEngine`保留13个原始int，包含相邻布尔字节的打包值；生产实现应按实际类型读取。

模式表 `base+0xBF74C0` 每项0x88，12项已读取，以下与本轮自然路径一致：

| 模式 | 子页面序列起点 | 实机稳定状态 |
| --- | --- | --- |
| 9，主页 | 41→42 | 全局42／43／1，自定义及选曲对象为空 |
| 2，节奏游戏／选曲 | 5→6 | 全局5／6／1，选曲对象状态6、有效可见PVID |
| 7，主页来源自定义 | 36→37 | 全局36／37／1，同时内部SceneManager键识别父页及子页 |

选曲R进入自定义时外层仍为5／6／1，内部SceneManager才区分父页1、模型2、发型3、饰品4。因此不能简单把模式7当成所有自定义来源。

自定义任务本体为 `base+0xCC6F100`，+0x68记录来源PVID、+0x70上下文、+0x78当前控制器。选曲激活后底层选曲的可见PVID读取可能变为-1；这是已有选曲读取字段在隐藏期间失效，必须在调用前取有效ID，并在退出后重新验证，不得宣称原曲丢失。

## 已验证协议

主页进入：确认主页、模式9、正常过程1、没有模式／子模式请求；在外层控制帧末调用`requestMode(7)`或`requestMode(2)`，等待原生任务销毁／初始化及独立页面断言。不要同时额外手动调用自定义激活器，模式7初始化已经调用它。

选曲进入自定义：确认真实选曲对象、状态6、有效PVID且没有自定义控制器；在匹配该选曲对象的控制帧末，依次调用`activateCustomize(pvid,null)`及`hideSelector(song,1)`；等待父页1，重新取得本轮控制器和场景树。

自定义退出：先从子页按已验证协议回父页。确认来源外层为5或36，父页空闲；在父页真实内部状态帧末请求`manager(target=8)`，受理后设置`controller+0x28=1`和`parentScene+0x19=1`，精确推进自然Esc分支的退出原因和完成标记。原生Finish负责收尾，宿主只等待来源恢复：5返回选曲，36返回主页。没有直接删除任务、强换场景节点或写全局菜单。自然Esc另有辅助调用，本协议未复刻音效等全部副作用；当前通过项是页面恢复和后续可操作性，仍需长期回归。

父页进入、子页切换、原生服装定位、预览与更换协议详见 `CURRENT_NATIVE_ROUTING_RESEARCH.md`。本轮完整流程不执行服装动作，仅定位316。
